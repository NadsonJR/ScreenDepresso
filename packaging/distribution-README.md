# ScreenDepresso — instaladores Linux

Este repositório distribui instaladores e metadados de atualização do ScreenDepresso. O desenvolvimento ocorre em um repositório privado separado.

## Download

Abra [a versão mais recente](../../releases/latest) e baixe o arquivo `.deb`.

Requer **Ubuntu 24.04 ou mais recente, x86_64 e sessão X11**.

```bash
sudo apt install ./screendepresso_*_amd64.deb
```

Abra **ScreenDepresso** no menu de aplicativos. Para versões futuras, use **Atualizações… → Verificar atualizações → Baixar e instalar**. Não é necessário compilar ou instalar Python.

O Ubuntu solicitará autorização para instalar a atualização. Salve suas edições e reabra o aplicativo após atualizar. O histórico de capturas é preservado.
